# Pokladna stromky

Mobilní pokladna pro prodej vánočních stromků (areál Castle, Svoboda nad Úpou).
Statická stránka, data v Supabase (tabulky `stromky_config` a `stromky_sales`).

## Nasazení na Render
New → Static Site → tento repozitář. Build command nechat prázdný, Publish directory `.`.

## Přidání na plochu telefonu
Otevři odkaz v Chrome → menu ⋮ → Přidat na plochu / Instalovat aplikaci.
